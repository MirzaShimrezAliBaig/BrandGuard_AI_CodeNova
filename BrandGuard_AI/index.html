    How cloud mode enforces access

    Cloud mode uses Supabase Auth, server-side session cookies, PostgreSQL Row Level Security and workspace membership checks. Local demo mode is not a substitute for multi-user authentication.

    Workflow guide

    How content moves through BrandGuard AI.

    1. 1Submit — paste your draft and optionally attach a visual asset.
    2. 2Evidence retrieval — approved knowledge is ranked against the content.
    3. 3Specialist checks — six separate checks produce findings with suggested fixes.
    4. 4Human review — send the item to the approval queue.
    5. 5Decision — a reviewer approves, requests changes or rejects, and the audit trail records it.
